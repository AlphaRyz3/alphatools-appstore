# AlphaTools App Store

A personal app store for [Runtipi](https://runtipi.io).

| App | Image | Default port |
|---|---|---|
| [VibraVid](apps/vibravid/metadata/description.md) | `ghcr.io/astraelabs/vibravid` | 8765 |
| [OpenWA](apps/openwa/metadata/description.md) | `ghcr.io/rmyndharis/openwa` | 2785 |

## Structure

Each folder in `apps/` holds one app:

- `config.json`: app settings and install form fields
- `docker-compose.yml`: dynamic compose, schema version 2
- `metadata/description.md`: the description shown in the store
- `metadata/logo.jpg`: a square logo

Secrets never go in this repository. They are install form fields, filled in or generated by Runtipi.

## How updates work

1. Every night at 02:00 UTC, the Renovate workflow looks for new image tags.
2. For a new tag, it updates the compose file and raises `tipi_version` and `version` in `config.json`.
3. It opens a pull request. Minor and patch updates merge automatically, while major updates wait for approval.
4. Runtipi syncs the store every 15 minutes and shows that an update is available.
5. Nothing changes on the server until the update is started from Runtipi.

Renovate only reads version numbers, so a breaking change can arrive in a minor or patch update. Check the release notes before updating an app.

## Tests

The tests validate every app's files, `config.json` and compose file against the Runtipi schemas:

```sh
bun install
bun test
```
